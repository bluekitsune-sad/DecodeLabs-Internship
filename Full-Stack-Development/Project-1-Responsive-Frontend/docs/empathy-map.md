# Empathy Map

Who are we designing for? Three personas of people visiting a local bakery.

## Persona 1 — The weekday regular

| Area          | Notes                                              |
| ------------- | -------------------------------------------------- |
| Says          | "I need a loaf for tonight. When is the oven done?"|
| Thinks        | "I hope sourdough is still left after work."       |
| Feels         | In a hurry, hungry, values routine                 |
| Does          | Glances at menu, checks bake times, exits quickly  |
| Needs         | Clear menu, visible bake times, minimal scrolling  |
| Pain           | Long navigation menus, cluttered layouts, slow pages |

## Persona 2 — The weekend visitor

| Area          | Notes                                                |
| ------------- | ---------------------------------------------------- |
| Says          | "Are you open on Sunday? Can we come early?"         |
| Thinks        | "Something special would be nice for the weekend."   |
| Feels         | Relaxed, curious, planning ahead                     |
| Does          | Reads about the bakery, checks opening hours         |
| Needs         | Clear hours, story/character, standout specials      |
| Pain           | Hiding hours behind a click, unclear days/closures   |

## Persona 3 — The celebration planner

| Area          | Notes                                                    |
| ------------- | -------------------------------------------------------- |
| Says          | "I want to reserve something for a party."               |
| Thinks        | "I hope custom orders are possible."                     |
| Feels         | Slightly anxious about timing, generous                  |
| Does          | Checks FAQ, fills in the contact form                    |
| Needs         | Reassurance, simple validation, obvious next step        |
| Pain           | Forms that fail silently, no confirmation, no FAQ        |

## Design takeaways

1. Menu and hours must be immediately visible — no treasure hunts.
2. Bake times stated on cards answer the regular's key question.
3. FAQ anticipates people who plan celebrations.
4. The form gives immediate, friendly feedback when something is wrong.
5. Large tap targets, readable text and clear focus states help every visitor.
