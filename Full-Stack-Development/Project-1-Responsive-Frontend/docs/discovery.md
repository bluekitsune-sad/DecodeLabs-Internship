# Discovery

## Challenge

Create a responsive frontend interface for a simple web application using
HTML5, CSS3 and vanilla JavaScript. No frameworks.

The interface must be:

- Responsive across mobile, tablet and desktop
- Mobile-first
- Built with semantic HTML
- Accessible (keyboard-friendly, focusable, labelled, readable)
- Coherent — one clear concept, not a random set of UI components

## Chosen concept

**Hearth & Crumb — artisan bakery website.**

Why this concept:

- A small local bakery has a clear audience and concrete needs
- Natural page structure: menu, about/hours, FAQ, contact
- Warm, grounded products match the required warm colour direction
- Bread imagery is not needed — the design works with typography, colour and
  layout, which keeps accessibility and performance simple

## Audience

- Local customers (walk-ins)
- People reserving baked goods by email
- Mobile users checking opening hours and weekend availability
- Anyone evaluating the page for readability and responsiveness

## Goals

- Show today's baked goods at a glance
- Communicate opening hours clearly
- Let customers reserve a loaf via a simple contact form
- Feel warm, honest and professional — like the bakery itself

## Content inventory

| Page area      | Content needed                                |
| -------------- | --------------------------------------------- |
| Header         | Brand name, primary navigation                |
| Hero           | Tagline, short intro, two calls to action     |
| Menu           | Six product cards with bake times             |
| About / hours  | Story paragraph + opening-hours sidebar       |
| FAQ            | Three native `<details>` items                |
| Visit          | Address + contact/reservation form            |
| Footer         | Address line, copyright, year                 |
