# DecodeLabs Internship

A portfolio of internship projects built for the DecodeLabs multi-track training
program. Every project is independent, runnable, documented, and GitHub-ready.

GitHub repository:

```text
https://github.com/bluekitsune-sad/DecodeLabs-Internship.git
```

## Repository structure

```text
DecodeLabs/
│
├── README.md
│
├── Artificial-Intelligence/
│   ├── Project-1-Rule-Based-Chatbot/
│   ├── Project-2-Data-Classification/

│
```
